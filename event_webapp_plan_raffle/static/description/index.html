Event Web App Plan - Raffle Prizes

The raffle prizes of an event day in the web app at /webapp_event (module event_webapp_plan), from the prize modules (event_raffle_prize_handover):

  • a "My prize" card for the logged-in winner: the button "Choose my prize" while the prize link is open, then the reserved prize and how it reaches the winner (pick-up location, email, shipping with its tracking number), then its hand-over;
  • the public name of the winners page, set from the card;
  • an "I am on site" toggle, shown on the registration and the draw for information only: the attendance of the raffles still comes from the check-in scan. The setting "On-site card" (off by default) shows it for every day.

The card follows the draws without reloading the page and says each change in the live region. Headings, lists, forms that work without script, text-only mode, no animation: the accessibility of the web app (WCAG 2.2 AA) is kept.
