Event Web App Plan - Agenda

The agenda of an event day in the web app at /webapp_event (module event_webapp_plan), read from the tracks of the events (module website_event_track): the program is typed once.

  • each room of the plan follows one track location, one room per location and per day;
  • the home page lists the published sessions of the day by start time, with their room, speaker and tags, the session in progress marked "Now" and the next ones "Next", and a filter by room that works without script;
  • under each room of the room list, its session in progress or its next one;
  • a room page lists the sessions of the room and announces the one that starts while the visitor is there.

Times show in the time zone of the event and follow the clock without reloading the page. Headings, lists, <time> elements, text-only mode, no animation: the accessibility of the web app (WCAG 2.2 AA) is kept.
